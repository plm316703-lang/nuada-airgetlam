## 4. 환경 메모 (이 PC에서 이미 해결한 것)

  `$resp = Invoke-WebRequest ... -UseBasicParsing; [Text.Encoding]::UTF8.GetString($resp.RawContentStream.ToArray()) | ConvertFrom-Json`

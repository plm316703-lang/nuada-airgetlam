## 2026-11-16 · step5 첫 학습과 평가 (`step5_train_csp_lda.py`)

**결정**
- 판별기: CSP(n_components=6, log) + LDA (교과서 기본 조합)
- **세션(날짜) 기준으로 분리**: 0train으로 학습, 1test로 평가. 실제 BCI는 어제 학습한 모델을 오늘 쓰기 때문
- 평가 세션으로 설정값을 고르지 않기로 함 (시험지를 보고 공부하는 셈). 설정 비교는 학습 세션 안 교차검증으로만 함
- 기준선: 평가 시행이 144개라 0.58 이상이어야 "찍기보다 낫다"고 판단

**구현**
- `assert`로 세션이 2개인지, 학습/평가 시행이 겹치지 않는지 확인
- 학습 세션 안에서 5-fold StratifiedKFold 교차검증 [A] + 평가 세션 정확도 [B]를 함께 계산

**검증 (피험자 5)**
- [A] 교차검증 0.541 ± 0.122, [B] 평가 0.549
- 해석: A와 B가 모두 낮음 → 날짜 차이 문제가 아님. 피험자 자체가 어렵거나 코드 문제 → step5b에서 구분

**문제와 해결**
- `TypeError: unexpected keyword argument 'n_compoents'` → 매개변수 이름 오타(n 누락). 교훈: `unexpected keyword argument`는 대부분 오타이며, IDE의 `Ctrl+P`로 매개변수 목록을 확인

**AI 도움**
- 코드 초안과 보완점 검토(assert, 교차검증, 기준선): Claude
- AI 안내 수정 사항: 처음에는 "n_components를 바꿔 평가 정확도를 비교하라"고 안내했으나, 평가 세션으로 값을 고르는 문제가 있어 정정함

# PACKET_LOSS — 연결 끊김 (워치독)

> Nuada Airgetlám 점검 매뉴얼 (연구용 프로토타입, 의료기기 매뉴얼 아님). 로봇팔 재개는 관제 화면의 수동 재개로만 한다.

## 증상
- 관제 화면의 "마지막 수신" 시간이 계속 늘어나고, 3초가 지나면 로봇팔이 정지되며 PACKET_LOSS 가 기록된다.
- 10초 이상 끊기면 "초기화 필요" 상태가 된다.

## 원인
- 판별기(Python 재생기) 프로그램이 멈추거나 종료됨.
- 네트워크 끊김, Wi-Fi 불안정, 방화벽.
- 판별기 PC의 과부하(다른 프로그램이 CPU를 많이 씀).

## 확인 방법
1. 판별기 프로그램 화면(터미널)에 오류가 있는지 확인한다.
2. 판별기가 "연결 실패/끊김 → 다시 연결" 메시지를 내는지 확인한다.
3. 같은 네트워크에서 관제 서버 주소에 접속되는지 확인한다.
4. API 키가 바뀌어 401로 거절되고 있지 않은지 확인한다.

## 해결 단계
1. 판별기 프로그램을 다시 실행하거나 네트워크를 복구한다.
2. 끊김이 10초 미만이었다면: 데이터가 다시 들어오고 연속 정상 데이터가 쌓이면 수동 재개를 요청한다.
3. 10초 이상이었다면: 먼저 "초기화"로 기본 자세로 되돌린 뒤, 연속 정상 데이터를 확인하고 수동 재개를 요청한다.
4. 자동 재개는 없다. 끊긴 사이 환자 상태가 바뀌었을 수 있으므로 환자 상태를 먼저 확인한다.

## 안 될 때
- 끊김이 반복되면 유선 네트워크로 바꾸고, 판별기 PC의 다른 프로그램을 종료한다.
- 원인을 찾지 못하면 세션을 종료한다.

# LINE_NOISE — 전원 잡음 (60Hz)

> Nuada Airgetlám 점검 매뉴얼 (연구용 프로토타입, 의료기기 매뉴얼 아님). 로봇팔 재개는 관제 화면의 수동 재개로만 한다.

## 증상
- 신호 품질이 급격히 낮아지고 판별기가 LINE_NOISE 를 보고한다.
- 거의 모든 채널에 같은 모양의 빠른 진동(60Hz, 한국 전원 주파수)이 겹친다.

## 원인
- 주변 전기 기기(충전기, 모니터, 형광등, 전동 침대)의 전자기 간섭.
- 기준(REF)·접지(GND) 전극 접촉 불량으로 공통 잡음이 제거되지 않음.
- 장비 전원 케이블과 전극 케이블이 가까이 꼬여 있음, 접지되지 않은 멀티탭 사용.

## 확인 방법
1. 최근에 켜거나 가까이 가져온 전기 기기가 있는지 확인한다.
2. 기준·접지 전극의 임피던스를 측정한다.
3. 장비가 배터리 모드인지, 접지된 콘센트에 연결되어 있는지 확인한다.
4. 전극 케이블이 전원 케이블과 나란히 지나가는지 확인한다.

## 해결 단계
1. 로봇팔은 이미 정지 상태다. 환자에게 잠시 기다려 달라고 안내한다.
2. 불필요한 전기 기기를 끄거나 1m 이상 떨어뜨린다.
3. 기준·접지 전극에 젤을 보충하고 다시 고정한다.
4. 전극 케이블을 한데 모으고 전원 케이블과 떨어뜨린다.
5. 신호 품질이 회복되고 연속 정상 데이터가 쌓이면 관제 담당자가 수동 재개를 요청한다.

## 안 될 때
- 장비를 배터리 전원으로 바꿔 차이가 있는지 본다.
- 소프트웨어 노치 필터는 원인을 가릴 뿐이므로, 원인을 찾기 전에는 판별 성능 평가에 쓰지 않는다.
- 계속되면 측정 장소를 바꾸거나 세션을 종료한다.

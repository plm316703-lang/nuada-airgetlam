# INVALID_MESSAGE — 메시지 규격 위반

> Nuada Airgetlám 점검 매뉴얼 (연구용 프로토타입, 의료기기 매뉴얼 아님). 로봇팔 재개는 관제 화면의 수동 재개로만 한다.

## 증상
- 관문이 INVALID_FORMAT, INVALID_FIELD, UNSUPPORTED_VERSION, OUT_OF_ORDER 로 메시지를 거부하고 로봇팔이 정지된다.

## 원인
- 판별기 프로그램이 예전 규격(버전 1)으로 메시지를 보냄 (버전 2는 신호 품질과 시간대가 필수).
- 판별기 코드 수정 중 칸 이름·값 범위가 바뀜.
- 같은 seq 번호를 다시 보냄 (재전송 버그).

## 확인 방법
1. 판단 기록의 사유와 상세(예: version=1, signal 없음)를 확인한다.
2. 판별기가 docs/message-spec.md 의 버전 2 규격을 따르는지 확인한다.

## 해결 단계
1. 판별기를 최신 재생기(realtime/replayer.py)로 실행한다.
2. 규격에 맞는 메시지가 연속으로 들어오면 관제 담당자가 수동 재개를 요청한다.

## 안 될 때
- 규격 문서와 판별기 코드를 함께 검토한다. 관문 검사를 느슨하게 바꾸지 않는다.
